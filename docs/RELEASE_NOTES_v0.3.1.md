# Forge v0.3.1

First public MIT-licensed release of Forge, preserving the v0.2 compatibility
contract and the v0.3 CommonMark, TOML, themes, publishing controls, collections,
taxonomy, archives and pagination features. The generator core is unchanged.

The repository and samples contain generic configuration. Release packaging
exports only validated source and privacy-safe validation summaries; local logs,
private operations reports and machine paths are not distributed. Binaries are
built with trimpath and record their exact public source commit.

Current limits include compile-only Windows ARM64 qualification, unsigned binaries,
whole-site rebuilds, no scheduler, escaped raw Markdown HTML and no GFM extensions.
